# WinLauncher — Windows 11 Launcher จำลอง (Android)

## วิธีสร้าง .apk (ผ่าน GitHub, ไม่ต้องลงอะไรในเครื่อง)
ดูขั้นตอนในแชทที่คุยกันไว้: อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่ → แท็บ Actions จะ build ให้อัตโนมัติ → โหลด .apk จาก Artifacts

## สิ่งที่ทำเสร็จแล้ว
### Window Manager
- เปิดหลายหน้าต่างพร้อมกัน ซ้อนกันได้ (multi-window)
- ลากแถบหัวหน้าต่างเพื่อย้ายตำแหน่ง, ลากมุมขวาล่างเพื่อปรับขนาด
- ปุ่ม _ (ย่อ) / □ (ขยาย-คืนขนาด) / ✕ (ปิด) มุมขวาบน ทำงานจริง
- แตะหน้าต่างไหนก็ยกขึ้นมาอยู่บนสุด (focus)

### Taskbar & Start Menu
- Taskbar ด้านล่าง โชว์หน้าต่างที่เปิดอยู่ทั้งหมด กดเพื่อสลับ/คืนจากที่ย่อไว้
- Start Menu แบบง่าย กดแล้วเปิดหน้าต่างใหม่
- ทั้งคู่เปลี่ยนสีตามโหมดมืด/สว่างอัตโนมัติ

### Personalize (วอลเปเปอร์ + ธีม)
- วอลเปเปอร์สำเร็จรูป 6 แบบ (Azure Bloom, Midnight Bloom, Sunset Glass, Ember Dark,
  Forest Mist, Graphite) — เป็นภาพ abstract ไล่สีที่สร้างขึ้นเอง ไม่ใช่ไฟล์ภาพลิขสิทธิ์ของ Microsoft
- สลับโหมดมืด/สว่างได้ทั้งระบบ (มีผลกับ taskbar, แถบหัวหน้าต่าง, สีตัวหนังสือ)
- เปิดแผงนี้ได้จาก: **กดค้างที่พื้นเดสก์ท็อป** (นิ้ว) หรือ **คลิกขวา** (ถ้าต่อเมาส์จริงกับแท็บเล็ต) → เลือก "Personalize"

### Desktop Icons
- ไอคอนตัวอย่าง 4 อัน (File Explorer, Settings, Notepad, Calculator) มุมซ้ายบน
- แตะสองครั้ง (double-tap) เพื่อเปิดเป็นหน้าต่างใหม่ — เหมือนพฤติกรรม Windows จริง

## ยังไม่ได้ทำ (ยังเป็นแค่หน้าต่างเปล่า ไม่ใช่แอปที่ทำงานจริงข้างใน)
- ⬜ **File Explorer ตัวจริง** — ตอนนี้กดแล้วเปิดแค่หน้าต่างเปล่า ยังไม่ได้ต่อกับไฟล์จริงในเครื่อง
- ⬜ **Settings app ตัวจริง** — ยังไม่มีหน้า Display/Sound/Bluetooth/Keyboard ข้างใน
- ⬜ **System bridge** — ปุ่ม Wi-Fi/battery/เวลาที่มุมขวาล่างของ taskbar ยังไม่ได้ใส่ (ยังไม่ดึงค่าจริงจากเครื่อง)
- ⬜ ปรับแสง/เสียงจริงผ่าน API ของเครื่อง
- ⬜ ตั้งเป็น Default Launcher (เปิดใช้ HOME intent-filter ที่คอมเมนต์ไว้ใน AndroidManifest.xml)
- ⬜ ปรับขนาด UI/cursor แบบ global scale

## หมายเหตุสำคัญ
โปรเจกต์นี้เป็นงานสร้างจริง ไม่ใช่แค่ mockup — ทุกปุ่มที่บอกว่า "ทำงานจริง" คือกดแล้วทำงานตามนั้นจริงในแอป
แต่เนื่องจากเป็นระบบใหญ่ (เทียบเท่า custom launcher เต็มรูปแบบ) จึงทยอยเพิ่มเป็นโมดูลไป
ยังไม่สามารถทำ "ทั้งระบบ" ให้เสร็จสมบูรณ์ในครั้งเดียวได้จริง — บอกได้เลยว่าอยากให้ทำโมดูลไหนต่อ

## การติดตั้งครั้งแรก
1. อัปโหลดโฟลเดอร์นี้ (รวมไฟล์ `winlauncher.keystore.jks` ด้วย — สำคัญมาก ห้ามลบ) ขึ้น GitHub repo
2. รอ GitHub Actions build เสร็จ → โหลด `app-debug.apk` จาก Artifacts
3. เปิดไฟล์ในแท็บเล็ต → อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก (ครั้งแรกครั้งเดียว) → ติดตั้ง

## การอัปเดตครั้งต่อๆ ไป (สำคัญ)
ตอนนี้ทุก build เซ็นด้วยกุญแจเดียวกันเสมอ (ไฟล์ `winlauncher.keystore.jks`) ดังนั้น:
- โหลด `app-debug.apk` เวอร์ชันใหม่มา แล้ว**กดติดตั้งทับได้เลย** ไม่ต้องถอนแอปเก่าออกก่อน
- ข้อมูล/การตั้งค่าที่เคยตั้งไว้ในแอปจะยังอยู่เหมือนเดิม
- **ห้ามลบไฟล์ `winlauncher.keystore.jks` ออกจาก repo เด็ดขาด** ถ้าลบแล้ว build ใหม่จะได้กุญแจคนละอันอีก จะกลับไปเป็นปัญหาต้องถอนแอปเก่าก่อนเหมือนเดิม

## เรื่อง "อัปเดตอัตโนมัติแบบไม่ต้องกดอะไรเลย"
พูดตรงๆ ว่า**ทำแบบสมบูรณ์ 100% ไม่ได้** ถ้าไม่ได้ลงผ่าน Play Store หรือ root เครื่อง เพราะ Android
บังคับให้ผู้ใช้กด "ติดตั้ง" ยืนยันเองทุกครั้งเพื่อความปลอดภัย (ป้องกันแอปแอบอัปเดตตัวเองเป็นมัลแวร์)
สิ่งที่ทำได้ดีที่สุดคือแบบนี้ (ที่แก้ให้แล้ว): โหลดไฟล์ใหม่มาวางทับ ติดตั้งทับได้เลยโดยไม่ต้องถอนของเก่า
ไม่ต้องเซ็ตแอปใหม่ ไม่ต้องจัดวางไอคอน/ตั้งค่าใหม่ — ใกล้เคียงคำว่า "อัปเดต" ที่สุดในเงื่อนไขนี้แล้ว
